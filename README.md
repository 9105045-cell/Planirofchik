# Мой первый планировщик

Личный веб-планировщик для ИП: клиенты и проекты, задачи, календарь повторяющихся дел, ручной учёт времени, стоимость услуг и расчёты с подрядчиками.

## Как открыть

Откройте `index.html` в Chrome или Edge. Установка, сервер и подключение к сети для локальной работы не нужны. Приложение использует три файла: `index.html`, `style.css`, `script.js`.

Для GitHub Pages источник публикации — ветка `main`, папка `/ (root)`. Файл `.nojekyll` включает публикацию готовых статических файлов без обработки Jekyll.

## Данные

Записи сохраняются в localStorage вашего браузера. Экспорт и восстановление всех записей доступны в разделе «Настройки» через JSON-файл. Между браузерами и устройствами автоматической синхронизации нет. Локальный файл и опубликованный сайт имеют отдельные хранилища: для переноса записей используйте резервную копию.

## Состояние проекта

Выполнены шаги 1–3 и исправления по результатам сверки с ТЗ. Акты, клиентские оплаты, сводные отчёты, экспорт в Excel, демонстрационные данные и окончательная приёмка запланированы в шагах 4–5 и пока отложены.

Подробности: `concept.md`, `tz.md`, `plan.md`. Проверочные сценарии, отчёты и снимки находятся в `.checks`; для работы самого приложения они не нужны.
